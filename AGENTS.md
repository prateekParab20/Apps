## Learned User Preferences

- Do not use Firecrawl MCP for research when it burns credits/tokens.
- Prefer Crawl4AI (Apache-2.0, Python, pages→markdown, self-run browsers, no credit meter) as the free replacement: https://github.com/unclecode/crawl4ai
- Other open-source crawl/extract options if needed: Crawlee (https://github.com/apify/crawlee), Scrapy for plain HTML (https://github.com/scrapy/scrapy), trafilatura for article text (https://github.com/adbar/trafilatura), or self-hosted Firecrawl without the cloud credit cap (https://github.com/firecrawl/firecrawl)

## Learned Workspace Facts

- For gymApp exercise demo images, prefer the public-domain free-exercise-db dataset (https://github.com/yuhonas/free-exercise-db) over scraping fitness apps.
