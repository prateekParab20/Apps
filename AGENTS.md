## Learned User Preferences

- Default research crawler: Crawl4AI (Apache-2.0, Python, pages→markdown, self-run browsers, no credit meter) — https://github.com/unclecode/crawl4ai. Install Playwright Chromium if needed (`python3 -m playwright install chromium`), then crawl locally. Do not use Firecrawl MCP / cloud Firecrawl for research (credit burn); user asked agents to remember this.
- Other open-source crawl/extract options if Crawl4AI is unavailable: Crawlee (https://github.com/apify/crawlee), Scrapy for plain HTML (https://github.com/scrapy/scrapy), trafilatura for article text (https://github.com/adbar/trafilatura), or self-hosted Firecrawl without the cloud credit cap (https://github.com/firecrawl/firecrawl)

## Learned Workspace Facts

- For gymApp exercise demo images, prefer the public-domain free-exercise-db dataset (https://github.com/yuhonas/free-exercise-db) over scraping fitness apps.
